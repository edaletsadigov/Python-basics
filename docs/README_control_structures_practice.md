# Control Structures Practice

Five exercises practicing `if/else`, `while` loops, and `for` loops through classic beginner problems.

## Exercises

1. **Even or Odd Checker** — `check_even_odd(num)` returns whether a number is even or odd using `if/else`.
2. **Sum Up To N** — `sum_upto_n(n)` adds all numbers from 1 to n using a `while` loop, with a guard against negative input.
3. **FizzBuzz** — `fizz_buzz(n)` prints "Fizz" for multiples of 3, "Buzz" for multiples of 5, "FizzBuzz" for both, and the number otherwise.
4. **Vowel Counter** — `count_vowels(text)` counts vowels (case-insensitive) in a string using a `for` loop.
5. **String Reverser** — `reverse_string(text)` returns a reversed string using slicing (`[::-1]`).

## Run

Open in Jupyter Notebook or Google Colab and run cells sequentially. No external libraries required.

## Requirements

Python 3.x
