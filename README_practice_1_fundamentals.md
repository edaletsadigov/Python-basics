# Practice 1 — Python Fundamentals

A set of 21 short exercises covering Python's core data types and built-in structures: numbers, strings, lists, dictionaries, and tuples.

## Topics Covered

- Checking and converting data types (`type()`, `int()`, `float()`)
- String methods — `upper()`, `lower()`, `capitalize()`, `replace()`, `split()`, `title()`, `format()`
- String indexing and length (`len()`, `index()`)
- List operations — `append()`, `extend()`, `insert()`, `remove()`, `pop()`, `sort()`, `clear()`
- Combining lists with `+` and unpacking (`[*a, *b]`)
- Dictionary operations — `update()`, `keys()`, `values()`, `get()`, `pop()`
- Tuple manipulation (converting to list, removing elements, converting back)
- `zip()` to pair two lists together

## Notes

Several exercises include more than one solution attempt (e.g. cell `2.1`, `3.1`) — this reflects trying different built-in methods to reach the same result and comparing them, rather than settling for the first approach that worked.

## Run

Open in Jupyter Notebook or Google Colab and run cells sequentially. No external libraries required beyond the Python standard library.

## Requirements

Python 3.x
