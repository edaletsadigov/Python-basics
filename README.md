# Python Basics 🐍

Small Python scripts and practice notebooks I wrote while learning the fundamentals — from core syntax to NumPy. Each one is standalone and runs from the terminal or Jupyter/Colab.

---

## Scripts

| File | What it does |
|------|-------------|
| [bmi_calculator.py](BMI_Calculator.py) | Calculates BMI and shows weight category |
| [palindrome_checker.py](pandilorme_Checker.py) | Checks if a word/phrase is a palindrome |
| [password_validator.py](Password_validator.py) | Validates password strength across 5 criteria |
| [numpy_vs_list_performance.py](numpy_vs_list_performance.py) | Benchmarks NumPy vs a Python loop on 1M elements |

---

## Practice Notebooks

| File | What it covers |
|------|-----------------|
| [practice_1_fundamentals.ipynb](practice_1_fundamentals.ipynb) | Data types, string methods, lists, dicts, tuples |
| [practice_2_data_types.ipynb](practice_2_data_types.ipynb) | Deeper dive into numbers, strings, bools, lists, dicts, tuples, sets |
| [control_structures_practice.ipynb](control_structures_practice.ipynb) | if/else, while loops, for loops, FizzBuzz |
| [numpy_practice.ipynb](numpy_practice.ipynb) | NumPy array creation, boolean indexing, filtering |

Each notebook and script has its own README with a breakdown of what was practiced.

---

## Run any script

```bash
python bmi_calculator.py
python palindrome_checker.py
python password_validator.py
python numpy_vs_list_performance.py
```

Notebooks open directly in Jupyter Notebook or Google Colab.

Python 3.x required. NumPy needed only for `numpy_vs_list_performance.py` and `numpy_practice.ipynb`:

```bash
pip install numpy
```
