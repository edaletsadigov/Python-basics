# Python Basics 🐍

Small Python scripts and practice files I wrote while learning the fundamentals — from core syntax to NumPy. Each one is standalone and runs from the terminal or Jupyter/Colab.

---

## Scripts

| File | What it does | Docs |
|------|--------------|------|
| [bmi_calculator.py](scripts/bmi_calculator.py) | Calculates BMI and shows weight category | [README](docs/README_bmi_calculator.md) |
| [palindrome_checker.py](scripts/palindrome_checker.py) | Checks if a word/phrase is a palindrome | [README](docs/README_palindrome_checker.md) |
| [password_validator.py](scripts/password_validator.py) | Validates password strength across 5 criteria | [README](docs/README_password_validator.md) |
| [numpy_vs_list_performance.py](scripts/numpy_vs_list_performance.py) | Benchmarks NumPy vs a Python loop on 1M elements | [README](docs/README_numpy_vs_list_performance.md) |

## Run any script

```bash
python scripts/bmi_calculator.py
python scripts/palindrome_checker.py
python scripts/password_validator.py
python scripts/numpy_vs_list_performance.py
```

Practice files open directly in Jupyter Notebook or Google Colab.

Python 3.x required. NumPy needed only for `numpy_vs_list_performance.py` and `numpy_practice.ipynb`:

```bash
pip install numpy
```
